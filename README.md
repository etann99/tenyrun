# 🚀 TENY RUN - Galaksia Teny Gasy

Un jeu spatial 3D immersif pour apprendre le vocabulaire malgache moderne de manière addictive.

## 🎮 Concept

Pilotez un vaisseau à travers 5 systèmes stellaires pour collecter 10 mots malgaches avant qu'une supernova n'engloutisse tout. Évitez les astéroïdes et ne touchez jamais le soleil !

## ✨ Fonctionnalités

### 5 Systèmes Stellaires
- **Teknôlôjia** (Technologie) - Cyan
- **Haikanto** (Arts) - Rose
- **Fanabeazana** (Éducation) - Violet
- **Fandraharahana** (Business) - Jaune
- **Haitarika** (Leadership) - Vert

### Gameplay
- ⏱️ **75 secondes** avant la supernova
- 🔤 **10 mots** à collecter par niveau
- ❤️ **100 points de vie** - attention aux astéroïdes !
- ⭐ **3 étoiles** : complétion + vitesse (<60s) + santé (>50%)
- 🌟 **Bonus** : +5 secondes par mot collecté
- 🎯 **Slow-motion** : 3 mots consécutifs sans collision

### Contrôles

#### Desktop
- **Z / S** : Monter / Descendre
- **← / →** : Gauche / Droite (relatif au vaisseau)
- **↑ / ↓** : Avancer / Reculer
- **Souris** : Cliquer-glisser pour rotation caméra 360°
- **Échap** : Pause

#### Mobile
- **Joystick** : Contrôle gauche/droite et haut/bas
- **2 doigts** : Glisser pour rotation caméra

### Mécaniques Avancées
- 🎲 **Physique réaliste** : Collisions élastiques avec rebond
- ☠️ **Danger solaire** : Toucher le soleil = mort immédiate
- 🌌 **Terrain étendu** : Explorez jusqu'aux limites du système
- 📊 **Barre de vie** : -10 HP par collision
- 🎨 **Esthétique cyberpunk** : Néon cyan/violet/rose, glassmorphism

### Progression
- 📚 **Glossaire** : Débloquez les traductions (FR/EN) en complétant les niveaux
- 🏆 **Système d'étoiles** : 3 niveaux de difficulté par système
- 💾 **Sauvegarde auto** : Votre progression est conservée
- 🌌 **Mode Infini** : Débloqué après 1★ minimum sur chaque système

### Interface
- ⏸️ **Pause** : Menu accessible en jeu
- 🔄 **Recommencer** : Relancer instantanément
- ❌ **Quitter** : Retour au menu principal
- 📖 **Glossaire intégré** : Consultez tous les mots appris

## 🎯 Objectifs d'Apprentissage

Teny Run prouve que le malgache peut véhiculer du vocabulaire moderne (tech/business/arts) de façon naturelle et addictive, via une expérience esthétique premium.

## 🚀 Installation

1. Ouvrez `index.html` dans un navigateur moderne
2. Tous les fichiers doivent être dans le même dossier :
   - `index.html`
   - `game.js`
   - `game-data.js`
   - `styles.css`

## 📱 Compatible

- ✅ Desktop (Chrome, Firefox, Safari, Edge)
- ✅ Mobile (iOS Safari, Chrome Android)
- ✅ Tablette

## 🎨 Crédits

- **Design** : Esthétique cyberpunk spatial
- **Typographie** : Orbitron + Rajdhani
- **3D Engine** : Three.js r128
- **Langue** : Malagasy (Malgache)

## 📝 Notes Techniques

- Pas de dépendances serveur
- Fonctionne 100% côté client
- localStorage pour la sauvegarde
- Optimisé pour performances mobile
- ~35 astéroïdes pour difficulté augmentée

## 🌟 Conseils de Jeu

1. **Maîtrisez la caméra** : Utilisez la souris pour voir autour de vous
2. **Les contrôles sont relatifs** : ↑ avance toujours dans la direction du vaisseau
3. **Évitez le soleil** : La zone rouge = mort instantanée
4. **Planifiez votre route** : Les mots sont dispersés partout
5. **Gérez votre santé** : Chaque collision compte !
